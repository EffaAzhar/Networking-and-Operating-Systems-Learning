# Ubuntu VM Setup Using UTM on macOS
This document outlines the setup process used to create an Ubuntu Linux virtual machine using UTM on macOS.
# Environment
- Host System: macOS
- Virtualization Platform: UTM
- Guest Operating System: Ubuntu 24.04 LTS (ARM64)
  
# VM Configuration
- Memory Allocation: 4 GB RAM
- CPU: 2 CPU cores
- Storage: Virtual disk allocated during setup

# Installation Steps
1. Installed UTM on macOS
2. Downloaded Ubuntu ISO
3. Created a new virtual machine
4. Configured memory and CPU allocation
5. Installed Ubuntu 24.04
6. Configured Linux user account
7. Completed Ubuntu setup process

# Security Configuration
To maintain separation between the host and guest environments:
- Shared folders were disabled
- Clipboard integration was minimized
- Linux environment isolated from macOS fileS
