# Networking and Operating Systems Learning
This repository documents my ongoing technical development in computer networking, operating systems, Linux environments, and cybersecurity monitoring concepts.
These studies support my research interests in behavioural monitoring, cyberattack visibility, SIEM technologies and cybersecurity monitoring within SME environments. The work in this repository was completed using Windows and Ubuntu virtual machines hosted on macOS through UTM virtualization.

The purpose of this project is to build a practical foundation in:

- Linux Administration
- Windows Administration
- Networking Fundamentals
- Process Management
- File Systems
- Permissions and Access Control
- Package Management
- Virtualization
- System Logging
- Cybersecurity Monitoring

These studies support my long term research interests in:

- Behavioural Monitoring
- Cyber Attack Visibility
- Sysmon Analysis
- SIEM Technologies
- Security Event Investigation
- SME Cybersecurity
